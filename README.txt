SHOE CLOSET
To open the site, double-click index.html (it works offline).
To add a shoe, open shoes.js in Notepad.
Copy one shoe block (from { to }) and paste it before the last ];
Change the details and give it a new id number.
Put photos in the images folder and write image: "images/filename.jpg".
Save the file, then refresh the page in your browser.
The three shoes marked EXAMPLE are samples; delete them when ready.
